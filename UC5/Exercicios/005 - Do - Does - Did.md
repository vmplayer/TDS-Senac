# Exercício 1 - Passe as frases para o inglês usando o Do / Does

### I

- Eu gosto de pizza? => Do I like pizza?
- Eu trabalho aos sábados? => Do I work on saturdays?
- Eu preciso estudar hoje? => Do I need to study today?

### You

- Você gosta de futebol? => Do You like soccer?
- Você mora perto da escola? => Do You live near school?
- Você gosta de assistir filmes? => Do You like to watch movies?

### He

- Ele trabalha aqui? => Does he work here?
- Ele gosta de música? => Does he like music?
- Ele estuda matemática? => Does he study math?

### She

- Ela mora em São Paulo? => Does she live in São Paulo?
- Ela joga video game todas as noites? => Does she play video game every night?
- Ela gosta de café? => Does she like coffee?

### It

- Isso funciona corretamente? => Does it work correctly?
- Isso precisa de bateria? => Does it need battery?
- Isso faz muito barulho? => Does it make much noise?

### We

- Nós temos aula esta quarta? => Do we have class this wednesday?
- Nós precisamos comprar comida? => Do we need to buy food?
- Nós trabalhamos juntos? => Do we work together?

### They

- Eles moram aqui? => Do they live here?
- Eles gostam de estudar? => Do they like to study?
- Eles andam de bicicleta? => Do they ride bikes?

# Exercício 2 - Frases Interrogativas e Negativas com o Do / Does

#### Perguntas:
* I
* You
* She

#### Negativas:
* He
* We
* I

### Interrogativas
* **Do I** have to do my lessons later?
* **Do You** care, after all?
* After everything **she does**, **do** you think you're still protecting her?

### Negativas
* **He doesn't** try to get out yet.
* **We don't** have the will to save you.
* **I don't** go to school.
